# 星舰：出发与归来

中文交互原理图：发射、热分级、两级回收，以及半透明猛禽发动机与内部流路。

## 查看方式

打开部署后的 GitHub Pages 地址即可。也可以下载 index.html，直接使用浏览器离线打开。

## 交互功能

- 按阶段按钮或拖动进度条，查看热分级和两级回收。
- 点击“只看发动机”，选择助推器、星舰海平面型或真空型。
- 调节外壳透明度，观察液氧、甲烷冷却与燃气排出的流动光点。
- 支持暂停、慢速、深浅主题和窄屏布局。

## GitHub Pages 设置

在仓库 Settings → Pages 中选择 Deploy from a branch，选择 main 分支和 / (root)，然后保存。
发布根目录是此文件所在目录；index.html 必须直接位于仓库根目录。
.nojekyll 用于关闭 Jekyll 处理。页面无需安装依赖，无需执行构建命令。

## 模型边界

尺寸采用指定的 70 米助推器＋50 米星舰、33＋6 台发动机构型。轨迹、时序和流速为教学示意；发动机流路省略预燃室与涡轮支路，不是制造图。
